# Hospital-La-Comarca
### CONTEXTO GENERAL

El hospital La Comarca tiene su inauguración para el 30 de diciembre de 2026, y entre sus requisitos considerados para funcionamiento solicita el desarrollo de una base de datos que cubra los siguientes rubros: 

* Control de medicamentos
* Roles de empleados
* Registro de empleados
* Sueldos y prestaciones
* Agenda de citas programadas
* Registro de especialidades disponibles
* Control de vacaciones (fijas, no variables en función de antigüedad, 2 semanas)
* Control de insumos internos (se ocupa comprar al menos 1 vez en x periodo de tiempo y requiere inventario, agregar clasificaciones, recordar q existe cocina) 
* Control de equipos médicos (cosas que requieren mantenimiento)
* Cuentas de pacientes
* Registro de pacientes
* Mantenimientos de equipos motorizados (ambulancias, carros empresariales)
* Balance de gastos/ingresos
* Registro de gastos de servicios básicos (agua, luz, gas)
* Expedientes clínicos 
* Recetas expedidas y cobradas dentro del hospital (no por fuera)
* Urgencias (atenciones, costos)
* Hospitalizaciones (cuartos disponibles, camas disponibles, altas, estancias, costos)
* Cirugías y quirófanos (agendas de citas, equipo médico reservado y quirófano asignado)
* Laboratorios y estudios de imagen (órdenes de estudio, resultados)
